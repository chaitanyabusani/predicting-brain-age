## Structure

- `data/` - raw or sample datasets (do **not** commit large raw data; use `.gitignore`).
- `notebooks/` - Jupyter notebooks for exploration and demos.
- `src/` - reusable modules and scripts.
- `models/` - trained models (git-lfs or external storage recommended).
- `requirements.txt` - Python dependencies.
- `README.md` - this file.

## Quickstart

1. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate   # macOS/Linux
venv\Scripts\activate    # Windows
pip install -r requirements.txt
```

2. Run main script or notebook:
```bash
python src/main.py
# or open notebooks in `notebooks/`
```
